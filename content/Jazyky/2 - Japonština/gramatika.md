# Slovesa
- většina japonských sloves je pravidelných a drží se přesných pravidel
- dělění
	- 一段 ichidan - "jeden sloupec"
	- 五段 godan - "pět sloupců"
- ichidan slovesa končí s ru a ru vždy dropnou při skloˇnování, všechno před る je kořen slovesa a zůstává tak jak je
- godan většinou končí s nějakým U

## negace
- ichidan - zahodit る a přidat ない

| Plain | Negative |
| ----- | -------- |
| 見る    | 見ない      |
| 食べる   | 食べない     |
- godan - nahradit "う" s "あ", pak přidat ない
- godan slovesa končící na う negativ používá わない, nikoliv あない

| Plain  | Negative |
| ------ | -------- |
| 殺**す** | 殺**さ**ない |
| 切**る** | 切**ら**ない |
| 書**く** | 書**か**ない |
| 買**う** | 買**わ**ない |
## Minulý čas
- na konec slovesa se přilípne た nebo だ
- změní se na posledním znaku na i, nejčastější je す -> し, ぬ -> に/ん, ku -> き/い
- 殺**す** - přítomný, 殺**し**た minulý
- う, つ a る se stává った
- す se stává した
- ぶ, む, ぬ se stává んだ
- く -> いた
- ぐ -> いだ
### ichidan
- vyměnit る za た

# Partikle
- přichází vždycky po slovu na který se lepí
- partikle definují roli slova ve větě jakože - tohle je podmět, tohle je předmět
- občas jde se na tohle vysrat, ale zpravidla to používají
- が označuje podmět věty
- を označuje předmět věty
- přísudek jde až za to
- ネコ**が**サカナ**を**食べる - kočka jí rybu
	- ネコ (kočka) - podmět
	- サカナ (ryba) - předmět
	- 食べる (jíst) - přísudek

častější:
- namísto podmětu označit téma/námět (topic) konverzace/věty
- は označuje topic, je to podobné/porovnávané s が
- může to označovat jako podmět tak předmět
- サカナ**は**ネコ**が**食べる - rybu, tu jí kočka (zhruba)
- ネコ**は**サカナ**を**食べる - kočka, ta jí rybu
- když použijeme が kde je očekávané použít を, dáváme tím extra důraz na to označené が
## Vlastnictví a přídavná jména
- の je partikl
- označuje vlastnictví a "přídavná jména"
- 私**の**ネコ - moje kočka
- velmi důležité
## に, へ a から
- から označuje začátek akce, je to takový "from"/od
- へ a に označuje konečný bod nebo směr akce, často jsou pretty much vyměnitelný. へ občas zní více formálně
- へ je více o pohybu a směru
- に je více o cílovém objektu
	- 東京**に**暮らす - žít v Tokyu
	- 学校**に**来る - přijít do školy
	- 朝の５時**に**起きた - probudil jsem se v 5 ráno

# přídavná jména
- dva typy přídavných jmen
## い-typ
- můžou být skloňována, jsou podobná slovesům
- **赤い**火 - červený oheň

- věta *něco je* stačí udělat normální *a je b* větu **bez だ nakonci**
	- 火が赤い - oheň je červený
	- です je actually v pohodě, ale je overly polite a nepřidává větě žádnou hodnotu

- suffix かった - minulost
- suffix くない - negace
- suffix くなかった - obojí

- いい má výjímku, to se skloňuje よい -> よかった / よくない

- vyměněním い za さ se z přídavného jména stane podstatné
	- 大き**い** - velký
	- 大き**さ** - velikost
